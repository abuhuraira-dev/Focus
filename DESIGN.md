# Approved design baseline

Preserve the current ivory, charcoal, and lime palette, system typography, rounded cards, whitespace, responsive navigation, and mobile button spacing. Preserve the landing-page structure and concise, direct copy. Change layouts only to resolve usability issues or when the user requests a redesign.

Primary audience: solo agency owners managing client delivery, deadlines, tasks, approvals, and payment follow-ups. Personal projects and skills remain available in the existing workspace.

Keep claims factual. Payment tracking is manual; no invoice sending, payment collection, background reminders, client portal, accounts, or cloud sync are implemented.
